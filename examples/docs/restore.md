# Restoring a backup

A restore replaces the current database and uploads folder with the contents of one backup archive. Take a new
backup first if you might need the current state again.

## Steps

1. Open Tools, then Backups, and pick the archive by its date.
2. Choose Restore and type the site name to confirm.
3. Wait for the progress bar to finish before you leave the page.

## If it fails

Repeat step 2 with maintenance mode switched on. If the restore stops again, the archive may be incomplete, so pick
the copy from the day before.

## Time needed

Restoring a 2 GB archive takes about ten minutes.
